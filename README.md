# portfolio

My personal portfolio, live at **https://lucantas.github.io/portfolio/**.

A static site with a pixel-art / RPG flavor: hero, an "inventory" of skills, a list of
projects with screenshot carousels, and a contact form. Available in English and Portuguese.

## Stack

- Plain HTML, CSS and vanilla JavaScript, no framework
- A tiny Node build (no dependencies) pre-renders every page so search engines and AI crawlers
  read the full content without running JavaScript
- Fonts from Google Fonts (Press Start 2P, Atkinson Hyperlegible)
- Pixel sprites drawn as inline SVG from character maps in `js/app.js`
- Contact form posts to [FormSubmit](https://formsubmit.co)
- Hosted on GitHub Pages from the `master` branch

## Structure

```
js/content.js     all copy (DICT), projects (JOBS), skills (GEAR), site config (SITE) and routes
js/app.js         sprites, project drawer (pushState), contact and privacy modals
css/site.css      all styles
scripts/build.mjs generates the pages below from js/content.js
scripts/lib/      page markup, SEO tags / JSON-LD, sitemap, robots.txt and llms.txt
imgs/             favicon, project screenshots (webp) and Open Graph images (imgs/og/)
```

Generated by the build (committed, because GitHub Pages serves the repo as is):

| Path                                       | Shows                               |
| ------------------------------------------ | ----------------------------------- |
| `index.html`, `pt/index.html`              | home (EN / PT)                      |
| `work/`, `pt/trabalhos/`                   | all projects                        |
| `work/<slug>/`, `pt/trabalhos/<slug>/`     | project drawer over the work list   |
| `sitemap.xml`, `robots.txt`, `llms.txt`    | crawler and AI discovery files      |

Old hash links (`#/trabalhos/<slug>`) redirect to the new paths.

## Editing content

1. Edit `js/content.js`.
2. Run `npm run build` and commit the generated files together with the change.
3. `npm test` checks every page: canonical, hreflang, one `h1`, Open Graph, JSON-LD and that
   every link resolves.

`SITE.url` drives canonical URLs, the sitemap and every internal link. Change it when the site
moves to its own domain and rebuild. A new project gets its share image from `imgs/og/<slug>.jpg`
(1200x630) when that file exists, otherwise `imgs/og/site.png`.

## Running locally

Internal links are absolute to the `SITE.url` path (`/portfolio/`), so serve the parent folder:

```bash
npm run build
cd .. && python3 -m http.server 8080
# open http://localhost:8080/portfolio/
```
